# BlenderMCP Pro / Ultra

AI assistant integration for Blender — connect Claude, GPT, or other
MCP-compatible assistants directly to your Blender scenes.

**A commercial product by Anvil Interactive Solutions.**
Available now on [Superhive](https://superhivemarket.com/products/blendermcp-pro).

## What it does

BlenderMCP Pro/Ultra exposes an MCP server inside Blender, letting an
AI assistant read scene state and drive Blender operations through
natural language — no manual clicking through menus.

## Features (v3.2.0)

- Studio profiles for consistent multi-project workflows
- Cross-session memory via local SQLite — the assistant remembers
  context between sessions
- Closed-loop render refinement — AI reviews render output and
  iterates automatically
- DeepSeek provider support alongside standard providers
- Tabbed N-panel UI inside Blender

## Example usage

Once installed, you can ask your assistant things like:
- "Reduce the polycount on the selected mesh while preserving edge flow"
- "Set up render settings matching my studio profile"
- "Review this render and suggest lighting adjustments"
